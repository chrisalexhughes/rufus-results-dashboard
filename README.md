# RUFUS Results Dashboard

Interactive browser-based dashboard for exploring RUFUS Light Assessment batch results, reviewing article feedback, filtering verdicts, and exporting uplift-ready article lists.

## Purpose

The dashboard allows users to:

- Review RUFUS assessment results.
- Filter articles by verdict.
- Search assessment outcomes.
- Review article-level feedback.
- Export uplift-ready article lists.

## Usage

1. Open the dashboard in a web browser.
2. Load a RUFUS assessment results file.
3. Filter and review results.
4. Export article lists as required.

## Technology

- HTML
- CSS
- JavaScript

No installation or server components are required.

## Updating

1. Edit `index.html`.
2. Commit changes to GitHub.
3. Netlify will automatically publish the update.
